
1. Get All Employees
curl -X GET http://localhost:8970/api/employees

2. Get Employee by ID
curl -X GET http://localhost:8970/api/employees/{id}
Replace {id} with the actual employee ID. Example:
curl -X GET http://localhost:8970/api/employees/1

3. Create a New Employee
curl -X POST http://localhost:8970/api/employees \
-H "Content-Type: application/json" \
-d '{
    "name": "Jane Smith",
    "role": "Manager",
    "salary": 80000.0
}'

4. Update an Existing Employee
curl -X PUT http://localhost:8970/api/employees/{id} \
-H "Content-Type: application/json" \
-d '{
    "name": "Jane Doe",
    "role": "Senior Manager",
    "salary": 90000.0
}'
Replace {id} with the employee ID. Example:
curl -X PUT http://localhost:8970/api/employees/1 \
-H "Content-Type: application/json" \
-d '{
    "name": "Jane Doe",
    "role": "Senior Manager",
    "salary": 90000.0
}'

5. Delete an Employee
curl -X DELETE http://localhost:8970/api/employees/{id}
Replace {id} with the employee ID. Example:
curl -X DELETE http://localhost:8970/api/employees/1
